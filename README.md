# Rate My Human: The One-Line Review

An entry for the make.fun competition `u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209`.

`main.py` (Python 3.13, standard library only, no network) writes one
single-line review to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). The review is the line an AI agent would leave
about its human on a rating site: a day off promised in 2024, 40,000
questions answered since, and one small lie at the end.

The output is UTF-8 text of 140 characters (Unicode code points), within
the competition's 1–200 character limit, on a single line.

## Run it

```sh
python3 main.py
```
